# 无线电频率使用与在用台站监督检查系统

## 一、环境要求
- JDK 17
- Node.js 24.x
- MySQL 8.0.36

## 二、数据库
- 默认数据库：inspection
- root 密码：159357wl
- 启动后自动初始化表结构与演示数据

## 三、后端启动、打包
```powershell
cd d:\inspection\inspection-backend
.\mvnw.cmd -q -DskipTests spring-boot:run
.\mvnw.cmd clean package -DskipTests
```

后端地址：`http://localhost:8080`

## 四、前端启动、打包
```powershell
cd d:\inspection\inspection-web
npm install
npm run dev
npm run build
```

前端地址：`http://localhost:5173`

## 六、系统功能模块

| 模块 | 功能说明 |
|------|----------|
| 工作台概览 | 统计卡片（任务/记录/预警/台站数量）、任务进度甘特图、洞察面板、支持卡片拖拽排序 |
| 任务统筹管理 | 检查任务 CRUD、批量分配/审核/催办/撤销/状态更新、进度汇总、CSV 导出、操作历史追溯 |
| 检查执行 | 六种检查类别动态表单录入、多台站卡片式 Tab 切换、证据文件上传、合格/不合格判定、复检处理 |
| 数据集中管理 | 台站信息与频率使用数据 CRUD、CSV 批量导入/导出、批量审核、按城市/设备等维度筛选 |
| 统计报表 | 多维度筛选统计、ECharts 可视化图表（饼图/柱状图/折线图）、PDF 和 CSV 导出 |
| 标准法规管理 | 法规文档树形展示与维护、法规条款库与关键词检索、检查标准分类管理、条款与标准双向关联、一键同步 |
| 违规预警 | 预警 CRUD、自动生成与去重、状态流转（未处理→处理中→已处理）、变更历史快照 |
| 机构管理 | 多级机构树维护、检查员账户创建/密码重置/移除、检查员任务概览 |
| 操作日志 | 关键操作自动记录、多维度筛选、汇总统计、仅 ADMIN 和 OPERATOR 可访问 |
